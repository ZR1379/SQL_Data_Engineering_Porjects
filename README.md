### 專案列表

#### [1. EDA](/1_EDA/) - 探索性資料分析 (Exploratory Data Analysis)
![Project 1 Overview](/images/1_1_Project1_EDA.png)

本專案以 SQL 為核心，運用進階查詢技術，針對資料工程師的就業市場趨勢進行深入分析。

**核心技能**：複雜多表聯結 (Complex Joins)、資料聚合 (Aggregations)、分析函數 (Analytical Functions)、資料品質驗證 (Data Quality Validation)

#### [2_DW_Mart_Build/](./2_DW_Mart_Build/) - 資料管線：資料倉儲與資料市集建置 (Data Pipeline - Data Warehouse & Mart)
![Data Pipeline Architecture](images/1_2_Project2_Data_Pipeline.png)
實作端到端 (End-to-end) 的 ETL Data Pipeline，將原始的 CSV 檔案轉換為星狀模型 (Star Schema) 的資料倉儲，以及分析性資料市集 (Data Marts)。

**核心技能**：維度建模 (Dimensional Modeling)、ETL 管線開發 (ETL Pipeline Development)、資料市集架構 (Data Mart Architecture)、生產環境實務 (Production Practices)
